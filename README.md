# marketpulse
## קבצים חדשים

- `portfolio.json` (אופציונלי): ההחזקות האמיתיות שלך, לפי הדוגמה ב-`portfolio.example.json`. כשהקובץ קיים, ניתוח הסיכון וקיבולת החשיפה נמדדים מולו ולא מול האיתותים שנרשמו.
- `review/report.md`: סקירה שבועית של טעויות, הטיות והזדמנויות שפוספסו.
- `backtest/`: דוחות הבדיקות ההיסטוריות. `fundamentals/`: נתונים פונדמנטליים שנאספים יומית לבדיקה עתידית.
